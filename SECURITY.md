# Security

## Secrets

These skills do not require API keys. Do not commit browser cookies, exported
session files, `.env` files, credentials, private transcripts, or local content
repositories.

If `--cookies-from-browser` is required for a public caption request, keep the
browser profile local. The scripts pass the profile selector to `yt-dlp`; they
do not copy cookie databases into this repository.

## Reporting

Please open a GitHub issue for a suspected vulnerability without including
credentials, personal data, private transcripts, or active session material.
